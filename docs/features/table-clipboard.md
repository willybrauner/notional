# Copy and paste cells

Cmd/Ctrl+C and Cmd/Ctrl+V work on the cells selected with the keyboard in a base table, pasting a value into several cells at once.

![Copy and paste cells](../images/table-clipboard.webp)

## How to use

- Select a cell with the arrow keys and press Cmd/Ctrl+C.
- Select one or more cells (Shift+arrows) and press Cmd/Ctrl+V: the value is pasted into all of them, in one step (Cmd/Ctrl+Z undoes it).

## Settings

*Settings → Notionalize → Bases*, on by default.

## Limits

- Relies on the copy and paste built into Obsidian's table, which can change with an Obsidian release.
- With text selected, or a cell being edited, copy and paste stay the usual text ones.

## What it writes

The pasted values, in the notes' frontmatter (written by Obsidian's table).

## Network

None.
